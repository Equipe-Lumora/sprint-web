# Projeto JOVI Smartphones

Este é um projeto de website para a empresa JOVI Smartphones, desenvolvido como parte da Sprint 2 do curso.

## Descrição

O site apresenta produtos de smartphones da marca JOVI, com funcionalidades como slideshow de imagens, carrinho de compras, sistema de login e cadastro, validação de formulários, e manipulação dinâmica de elementos DOM.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)

## Funcionalidades

- Slideshow automático e manual de imagens de produtos
- Adição de produtos ao carrinho
- Sistema de login e cadastro com validação
- Manipulação dinâmica de elementos (adicionar produtos)
- Alertas e prompts para interações do usuário
- Armazenamento local para usuários e carrinho

## Como Executar

1. Abra o arquivo `index.html` em um navegador web.
2. Navegue pelas seções usando o menu.
3. Cadastre-se e faça login.
4. Adicione produtos ao carrinho.
5. Use os controles do slideshow.

## Requisitos Atendidos

- Manipulação dinâmica de elementos e eventos
- Validação de formulários e login
- Alertas e prompts
- Manipulação de imagens (slideshow)
- Criação e gerenciamento de eventos DOM
- Código puro em JavaScript, sem frameworks externos
